# MVP Scope

This document defines the minimum viable scope for the first version of the EduCompare project.

1. MVP Features (V0.0)

    - The "Real-Cost" Calculator
    Instead of just showing tuition, create a table or interactive tool that calculates the Total Estimated Investment.

    Feature: Input a university and major; output a breakdown including tuition, mandatory health insurance, estimated visa fees, and monthly living costs in that specific city (e.g., Bangkok vs. Taipei).

    Data Goal: Expose "hidden fees" that agents often hide to make a university look cheaper.

    - Side-by-Side "Major Matcher"
    A comparison tool specifically for Thailand and Taiwan universities.

    Feature: Allow users to pick two universities and see a direct comparison of:

    Teaching Style: Classified as Practical/Vocational (hands-on) vs. Research/Theory (academic).

    Admission Requirements: Minimum GPA, language proficiency (IELTS/TOCFL/HSK), and deadline dates.

    International Student Ratio: To show how "global" the campus actually is.

    - The "Legal Guardrail" Dashboard
    A dedicated section for work and visa rights to prevent students from being tricked into illegal labor.

    Feature: A clear display of the current legal regulations for the chosen country:

    Taiwan: Max 20 hours/week part-time work (requires work permit).

    Thailand: Restrictions on student work (often very limited).

    Data Goal: Directly contradicts agents who "guarantee" jobs that might be illegal or non-existent.

    - Search & Filter by "First-Gen" Priorities
    Most sites filter by "Rankings." Your MVP should filter by Accessibility.

    Filters:

    "No Application Fee"

    "Full/Partial Scholarship Available"

    "English-Taught Programs"

    "Low Initial Deposit" (important for middle-class cash flow).

    - Verified "Red Flag" Checklist
    A simple, static guide built into the app.

    Feature: A "Scam Alert" sidebar that tells students: "If an agent asks for a fee for 'guaranteed admission,' it’s a red flag. Official university applications usually cost [X] amount."
